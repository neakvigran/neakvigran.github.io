# Solution

## Directory Enumeration

Started with `dirb` against the web root to look for hidden files/directories.

![image-1196](/assets/img/obsidian/room-404/image-1196.png)

`.git/HEAD` returns `200 OK` — the application's `.git` directory is exposed on the live web server. This is a classic misconfiguration a git repo deployed alongside the app without excluding the `.git` folder.


## Confirm Exposure

Browsed directly to the `.git` path to confirm directory listing is enabled.

![image-1197](/assets/img/obsidian/room-404/image-1197.png)

Full directory listing of the `.git` internals is available that enough to reconstruct the entire repository, including its commit history.

## Dump the Repository

Used `git-dumper` to pull down the full repo from the exposed `.git` directory.

![image-1198](/assets/img/obsidian/room-404/image-1198.png)


`git-dumper` recursively fetches every object, ref, and log needed to rebuild the working tree locally in the `repo/` folder.


## Recover the Source & Find the Flag

With the repo reconstructed locally, listed the files and read the `README.`

![image-1199](/assets/img/obsidian/room-404/image-1199.png)

![image-1201](/assets/img/obsidian/room-404/image-1201.png)

And we found the flag!
